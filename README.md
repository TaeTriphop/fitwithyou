# FitWithYou

เว็บแอพบันทึกการเล่นฟิตเนสของคุณกับแฟน บอกได้ว่าท่านี้ยกเท่าไร เล่นครบเซ็ทไหม มีท่าอะไรบ้าง วันไหนเล่นอะไร และหน้าภาพรวมบอกว่าแต่ละคนแข็งแรงขึ้นแค่ไหนตั้งแต่เริ่ม

เป็น HTML + CSS + JavaScript ล้วน ไม่ต้อง build เก็บข้อมูลบน Supabase ทั้งสองเครื่องจึงเห็นข้อมูลชุดเดียวกัน เข้าแอพด้วยรหัสวันครบรอบ ใส่ครั้งเดียวต่อเครื่อง

## ตั้งค่า Supabase (ทำครั้งเดียว)

1. สมัครที่ supabase.com กด New project ตั้งรหัสผ่านฐานข้อมูล (จดไว้) และเลือก Region เป็น Singapore
2. ไปที่ **SQL Editor** กด New query วางเนื้อหาทั้งหมดของไฟล์ `supabase-setup.sql` (ไฟล์ที่อยู่นอกโฟลเดอร์นี้) แล้วกด Run
3. ไปที่ **Project Settings > API** (หรือ Data API / API Keys) คัดลอก Project URL กับคีย์ anon public
4. เปิดไฟล์ `js/config.js` ในโฟลเดอร์นี้ แล้ววางทั้งสองค่าลงไป

`supabase-setup.sql` มีรหัสวันครบรอบอยู่ข้างใน **ห้ามอัปโหลดขึ้น GitHub** รันใน Supabase เสร็จแล้วเก็บไว้ในเครื่องก็พอ ส่วนตัวแอพไม่มีรหัสอยู่ในโค้ดเลย Supabase เป็นคนตรวจ

อยากเปลี่ยนรหัส: แก้ตัวเลขใน `create or replace function public.app_pin_ok()` ในไฟล์นั้น แล้วรันเฉพาะคำสั่งนั้นใน SQL Editor ทุกเครื่องจะต้องใส่รหัสใหม่

Supabase แบบฟรีอาจหยุดโปรเจกต์ชั่วคราวถ้าไม่มีการใช้งานนานราวหนึ่งสัปดาห์ ถ้าเปิดแอพแล้วขึ้นว่าเชื่อมต่อไม่ได้ ให้เข้า Dashboard แล้วกด Restore project

## ขึ้น GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository (ให้ `index.html` อยู่ชั้นบนสุด)
2. Settings > Pages > Deploy from a branch > เลือก `main` และ `/ (root)` > Save
3. เปิดลิงก์บนมือถือทั้งสองเครื่อง ใส่วันครบรอบ แล้วกด "เพิ่มลงหน้าจอโฮม"

ถ้าเว้น `js/config.js` ว่าง แอพจะเก็บข้อมูลในเบราว์เซอร์แทนและไม่ถามรหัส ใช้ทดลองได้แต่ไม่ซิงก์ระหว่างเครื่อง ทดสอบบนคอมด้วย `python3 -m http.server` แล้วเปิด `http://localhost:8000`

## ใช้งาน

- **ตาราง** แผนจันทร์ถึงอาทิตย์ ใช้ซ้ำทุกสัปดาห์ แตะวันเพื่อดู แตะท่าเพื่อแก้น้ำหนัก เซ็ท ครั้ง หรือย้ายวัน
- **เล่นไม่ตรงวัน** แตะวันที่อยากเล่นแผนนั้น แล้วกด "วันนี้เล่นแผนวัน…แทน"
- **บันทึก** แตะท่า แล้วกดว่าทำได้กี่เซ็ท (แตะซ้ำเพื่อยกเลิก) หรือกด "ทั้งคู่ครบทุกเซ็ท" น้ำหนักจำค่าล่าสุดไว้ให้ แตะตัวเลขน้ำหนักเพื่อพิมพ์ได้
- **อยากเล่นท่าอื่น** ในหน้าวันนี้กด "เพิ่มท่าเฉพาะวันนี้" แล้วแตะหมวด เช่น ขา จะเห็นท่าขาทั้งหมดในคลัง
- **ภาพรวม** เปอร์เซ็นต์ที่แข็งแรงขึ้นตั้งแต่เริ่มของแต่ละคน สรุปเดือนนี้ สถิติใหม่ และรายท่า แตะท่าเพื่อดูกราฟ

## ใส่รูป

รูปโปรไฟล์ใส่ที่ตั้งค่า รูปท่าใส่ที่คลังท่า > แก้ไขท่า ใช้รูปจากเว็บไหนก็ได้ ขอแค่เป็นลิงก์ของตัวรูป: กดค้างที่รูปแล้วเลือก "คัดลอกที่อยู่รูปภาพ" ลิงก์ของโพสต์ IG/TikTok/Pinterest ใช้ไม่ได้ ถ้าไม่ใส่หรือรูปโหลดไม่ขึ้น จะแสดงตัวอักษรแทน

## โครงสร้างไฟล์

```
index.html                  หน้าหลัก + แถบเมนูล่าง
css/styles.css              หน้าตาทั้งหมด (รองรับโหมดมืด)
js/config.js                ★ ใส่ค่า Supabase ตรงนี้
js/app.js                   เปลี่ยนหน้าและรับการกดปุ่ม
js/domain.js                ตรรกะ: แผน ผลการเล่น การเปรียบเทียบ สถิติ ค้นหา
js/data/store.js            ชั้นข้อมูลกลาง + จำรหัสในเครื่อง
js/data/adapter-supabase.js อ่าน/เขียน Supabase (แนบรหัสไปกับทุกคำขอ)
js/data/adapter-local.js    อ่าน/เขียน localStorage
js/views/pin.js             หน้าใส่วันครบรอบ
js/views/schedule.js        ตาราง
js/views/workout.js         หน้าวันนี้ + แผ่นบันทึก
js/views/overview.js        ภาพรวม
js/views/library.js         คลังท่า
js/views/settings.js        ตั้งค่า
```
