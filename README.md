# FitWithYou

เว็บแอพบันทึกการเล่นฟิตเนสของคุณกับแฟน ตอบ 5 เรื่อง: ท่านี้ยกเท่าไร เล่นครบเซ็ทไหม มีท่าอะไรบ้าง ท่าไหนทดแทนได้ และวันไหนเล่นอะไร พร้อมหน้าภาพรวมที่เทียบครั้งล่าสุดกับครั้งก่อน

เป็น HTML + CSS + JavaScript ล้วน ไม่ต้อง build เก็บข้อมูลบน Supabase เพื่อให้คุณกับแฟนเห็นข้อมูลชุดเดียวกันทั้งสองเครื่อง

## ตั้งค่า Supabase (ทำครั้งเดียว ประมาณ 10 นาที)

1. สมัครที่ supabase.com แล้วกด New project ตั้งชื่ออะไรก็ได้ ตั้งรหัสผ่านฐานข้อมูล (จดไว้) และเลือก Region เป็น Singapore จะเร็วที่สุดสำหรับไทย
2. รอโปรเจกต์สร้างเสร็จ ไปที่เมนู **SQL Editor** กด New query วางเนื้อหาทั้งหมดของไฟล์ `supabase/schema.sql` แล้วกด Run
3. ไปที่ **Authentication > Users** กด Add user > Create new user ใส่อีเมลกับรหัสผ่านที่คุณกับแฟนจะใช้ร่วมกัน และติ๊ก Auto Confirm User
4. **สำคัญ:** ไปที่ Authentication > Sign In / Providers (บางเวอร์ชันอยู่ใน Settings) แล้วปิด **Allow new users to sign up** เพื่อไม่ให้คนอื่นสมัครบัญชีเข้ามาดูข้อมูลได้
5. ไปที่ **Project Settings > API** (หรือ Data API / API Keys) คัดลอก Project URL กับคีย์ anon public
6. เปิดไฟล์ `js/config.js` แล้ววางทั้งสองค่าลงไป

ถ้าเว้น `js/config.js` ว่างไว้ แอพจะเก็บข้อมูลในเบราว์เซอร์แทน ใช้ทดลองได้ แต่จะไม่ซิงก์ระหว่างเครื่อง

คีย์ anon อยู่ในหน้าเว็บสาธารณะได้ตามปกติ เพราะตารางทุกตารางเปิด RLS ไว้ให้เข้าถึงได้เฉพาะคนที่เข้าสู่ระบบแล้ว (และข้อ 4 ทำให้ไม่มีใครสมัครเพิ่มได้)

Supabase แบบฟรีอาจหยุดโปรเจกต์ชั่วคราวถ้าไม่มีการใช้งานนานราวหนึ่งสัปดาห์ ถ้าเปิดแอพแล้วโหลดข้อมูลไม่ได้ ให้เข้า Dashboard แล้วกด Restore project

## ขึ้น GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository (ให้ `index.html` อยู่ชั้นบนสุด)
2. Settings > Pages > Deploy from a branch > เลือก `main` และ `/ (root)` > Save
3. เปิดลิงก์ที่ได้บนมือถือทั้งสองเครื่อง เข้าสู่ระบบครั้งเดียว แล้วกด "เพิ่มลงหน้าจอโฮม"

ทดสอบบนคอมได้ด้วย `python3 -m http.server` แล้วเปิด `http://localhost:8000` (ดับเบิลคลิกเปิดไฟล์ตรงๆ จะไม่ทำงาน)

## ใช้งาน

- **ตาราง** แผนจันทร์ถึงอาทิตย์ ใช้ซ้ำทุกสัปดาห์ แตะวันเพื่อดู แตะท่าเพื่อแก้น้ำหนัก เซ็ท ครั้ง หรือย้ายวัน
- **เล่นไม่ตรงวัน** เช่นเมื่อวานไม่ได้ไป ให้แตะวันของเมื่อวานในหน้าตาราง แล้วกด "เล่นแผนนี้วันนี้" หรือกด "เปลี่ยนแผน" ในหน้าวันนี้ก็ได้
- **บันทึก** แตะท่า แล้วกดว่าทำได้กี่เซ็ท (กดซ้ำเพื่อยกเลิก) ถ้าครบทั้งคู่กด "ทั้งคู่ครบทุกเซ็ท" ครั้งเดียว น้ำหนักจะจำไว้ใช้ครั้งหน้าเอง แตะตัวเลขน้ำหนักเพื่อพิมพ์ได้
- **เครื่องไม่ว่าง** ในแผ่นบันทึกจะมีท่าหมวดเดียวกันให้กด "เล่นแทน" เฉพาะวันนั้น
- **ภาพรวม** เทียบครั้งล่าสุดกับครั้งก่อนของทุกท่า ว่าพัฒนา เท่าเดิม หรือลดลง

## ใส่รูป

ใส่รูปโปรไฟล์ได้ที่ตั้งค่า และรูปท่าได้ที่คลังท่า > แก้ไขท่า ใช้รูปจากเว็บไหนก็ได้ (Pinterest, Google รูปภาพ ฯลฯ) ขอแค่เป็นลิงก์ของตัวรูป: กดค้างที่รูป แล้วเลือก "คัดลอกที่อยู่รูปภาพ" ลิงก์ของโพสต์ (เช่น pin.it, instagram.com/p/…, tiktok.com) ใช้เป็นรูปไม่ได้ ถ้าไม่ใส่หรือรูปโหลดไม่ขึ้น จะแสดงตัวอักษรแทน

## โครงสร้างไฟล์

```
index.html                  หน้าหลัก + แถบเมนูล่าง
css/styles.css              หน้าตาทั้งหมด (รองรับโหมดมืด)
js/config.js                ★ ใส่ค่า Supabase ตรงนี้
js/app.js                   เปลี่ยนหน้าและรับการกดปุ่ม
js/domain.js                ตรรกะ: แผน ผลการเล่น การเปรียบเทียบ ท่าทดแทน ค้นหา
js/data/store.js            ชั้นข้อมูลกลาง (เลือก Supabase หรือ localStorage ให้เอง)
js/data/adapter-supabase.js อ่าน/เขียน Supabase + เข้าสู่ระบบ
js/data/adapter-local.js    อ่าน/เขียน localStorage
js/views/schedule.js        ตาราง
js/views/workout.js         หน้าวันนี้ + แผ่นบันทึก
js/views/overview.js        ภาพรวม
js/views/library.js         คลังท่า
js/views/settings.js        ตั้งค่า
js/views/login.js           เข้าสู่ระบบ
supabase/schema.sql         สร้างตารางบน Supabase
```
